# First Outreach Targets

Goal: get feedback from builders deploying AI agents with real tool access.

## Target Profiles

- AI agent framework maintainers
- MCP server builders
- security engineers testing agents
- devtools founders
- platform engineers experimenting with coding agents
- compliance/security consultants working with AI adoption

## Message Angle

"I am building AION, a runtime firewall for AI agent tool calls. It blocks risky MCP actions and leaves audit receipts. Could you try the one-command demo and tell me what policy controls your team would need before trusting agents?"

## Proof To Include

- blocked destructive shell command
- blocked secret exfiltration
- allowed safe tool call
- JSONL receipt trail

## First Milestone

Get 20 serious conversations, not vanity likes.

Track:

- name
- role
- company/project
- what agents/tools they use
- risk they care about
- willingness to test AION
- willingness to pay for team/compliance features
