# Website Copy

## Headline

AION Core

## Subheadline

Runtime security for AI agents: firewall, receipts, scan, and approvals for real tool calls.

## Short Description

AION Core sits between AI agents and tools. It blocks risky MCP calls, writes
hash-verified receipts, scans weak configs, and creates team approval decisions.

## Install

```powershell
pip install aion-core
aion-demo
```

## Positioning

AION is not just an agent tool. It is the beginning of a trust and security
control plane for AI agents.

## Launch CTA

- Try the one-command demo.
- Add AION in front of an MCP server.
