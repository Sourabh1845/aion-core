AION Core is an open-source control layer that sits between AI agents and real-world tools. It decides what can run, what must be blocked, what needs human approval, and what evidence should be recorded.

What AION Core Does

Runtime Guard

Checks agent actions before they hit shell, files, APIs, databases, tools, or MCP servers.

MCP Firewall

Wraps stdio MCP servers and blocks risky tools/call requests before execution.

Receipts

Writes hash-verifiable JSONL evidence for allow, block, and approval-required decisions, with optional HMAC signatures.

Risk Scan

Scans MCP configs and policies for weak coverage, unprotected servers, and dangerous surfaces.

Team Policy

Turns sensitive actions into approval-required decisions with approval logs and Slack-ready payloads.

Control View

Summarizes receipts, blocked actions, pending approvals, and agent activity for operators.

Current Status

AION Core is an MVP-complete open-source prototype for AI action control. It is ready for demos, early technical feedback, and real integration tests. It now includes local signed-receipt verification, but it is not yet a production enterprise SaaS.
