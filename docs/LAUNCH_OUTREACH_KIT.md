# Launch Outreach Kit

## Public Launch Post

```text
I launched AION Core 0.8.0 today.

AION Core is an open-source runtime security layer for AI agents:
- MCP tool-call firewall
- Guard runtime action checks
- Scan for weak MCP configs/policies
- hash-verified receipts
- team approval-required decisions

Install:
pip install aion-core
aion-demo

GitHub:
https://github.com/Sourabh1845/aion-core

PyPI:
https://pypi.org/project/aion-core/

I am looking for feedback from MCP builders, AI agent developers, security engineers, and teams giving agents real file/shell/API/cloud access.
```
